07 / RESEARCH
Move to see.ACTIVE PERCEPTION / OCCLUSION

The research challenge

Where should a robot move to see the features it needs for manipulation?

Rather than treating perception as a single image, active vision uses robot motion to improve observations. 3D Move to See samples multiple viewpoints and uses semantic visual information to guide the robot towards a better view of its target.

What the work involves

  • Sample changes in target visibility across multiple viewpoints.
  • Use visual servoing to move towards informative views.
  • Study the link between occlusion, robot motion and manipulation.
Context & scope

Active vision addresses missing visual information. Physical access is a separate challenge, motivating the complementary work on touch-guided canopy interaction.
